# OLA Ride Analytics Dashboard (SQL + Power BI)

## 📌 Project Overview
An end-to-end data analytics project analyzing *100,000+ ride booking records* for OLA. The project focuses on booking trends, revenue drivers, cancellation patterns, vehicle category performance, and driver/customer ratings to deliver actionable business insights.

---

## 🛠️ Tech Stack & Tools
- *Database / Querying:* SQL (MySQL)
- *Data Visualization:* Power BI
- *ETL & Data Cleaning:* SQL Queries & Views
- *Dataset:* 100k+ Ride Booking Records

---

## 🔑 Key Insights & SQL Analysis
1. *Total Bookings & Value:* Processed over 103K+ total bookings generating over ₹35M in total booking value.
2. *Cancellation Analysis:* Identified cancellation drivers (Driver vs Customer) and calculated an overall cancellation rate (~28%).
3. *Vehicle Performance:* Evaluated average ride distances across categories (Prime Sedan, Prime SUV, Auto, Bike, E-Bike, Mini).
4. *Payment Preferences:* Analyzed revenue generated by UPI, Cash, Credit Card, and Debit Card modes.
5. *Customer & Driver Ratings:* Tracked satisfaction metrics across all vehicle categories to evaluate driver service quality.

---

## 📊 Power BI Dashboard Highlights
- *Overall Page:* High-level KPIs (Total Bookings, Booking Value, Ride Volume over time).
- *Vehicle Type:* Performance distribution and average distance per vehicle type.
- *Revenue:* Payment mode distribution and Top 5 Customers by booking value.
- *Cancellation:* Drivers vs Customers cancellation reasons and cancellation rate.
- *Ratings:* Driver vs Customer rating metrics.
